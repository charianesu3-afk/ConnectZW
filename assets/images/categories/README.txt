CATEGORY PHOTOS
===============
Put one real photo per category in THIS folder (assets/images/categories/).
Use the exact file name below (.jpg, .jpeg, .png or .webp). Ideal size: about 800 x 500 pixels, landscape.
Free photo sources: unsplash.com and pexels.com (check each photo's licence).
Categories without a photo show an icon instead. In the Admin dashboard, open the 'Photos' tab to see what is missing.

If you still have the photos from your first ConnectZW project (accounting.jpg, plumbers.jpg, saloon.jpg ...),
copy that old assets/images folder's files into the new assets/images folder. They are picked up automatically.
